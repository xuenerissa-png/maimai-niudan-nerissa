# 麦麦扭蛋 · nerissa

**按你的口味、预算和热量目标，摇出今天这一餐。**

面向支持本地 Skill 的 AI 助手的趣味组餐技能。用户说“摇个麦门”，助手会结合预算、必选餐品、口味和可选的单餐热量上限，使用麦当劳中国官方 MCP 查询真实菜单、核价，并生成一句轻松的餐桌寄语（不涉及运势预测）。

视觉图沿用项目早期名称“麦门天意”，当前名称为“麦麦扭蛋”。这是产品的早期概念设计，用于展示视觉方向与交互构想，非已上线界面。当前可运行版本是 AI 助手 Skill 与 Python CLI，尚未实现图中的手机界面、3D 动画、历史记录或收藏页。图中餐品、价格和文案为概念占位，不作为实时菜单、核价或营养数据。

## 目标用户

想减少点餐纠结、按预算和单餐热量目标挑选麦当劳餐品的用户，以及希望在 AI 助手中复用 MCP 组餐流程的开发者。

## 安装 Skill

克隆本仓库，将整个目录作为本地 Skill 导入支持 SKILL.md 的 AI 助手。以 Codex 为例，可把完整目录放到 `~/.codex/skills/maimai-niudan-nerissa`，重新载入技能后说“摇个麦门”。其余助手按各自本地技能导入方式安装；只使用 CLI 则直接在仓库目录运行下述命令。

## 已实现

- 官方 MCP Streamable HTTP 客户端、鉴权、工具发现和实际参数查询。
- 会话式组餐、锁定餐品及重新摇餐，通过 Skill 指导助手执行；不是独立网页或自动优化求解器。
- 到店自取门店查询、菜单与套餐详情、整单官方核价。
- 官方营养数据适配、标准份量热量汇总、单餐热量上限比较；缺失或特调餐品标为未知，不把未知项计为零。
- 确认后创建自取订单；提交前重新核价并检查确认金额上限。支付由用户在官方页面或 App 完成。
- 创建后查询订单状态；创建请求不自动重试，避免重复订单。

## 第一次使用：先连接麦当劳

**Token 就是麦当劳提供给你的个人连接凭证，只需在自己的电脑上填一次。** 不用修改源码或配置文件，也不要把它发给 AI 助手。

1. **下载项目**：点击本页绿色 `Code` → `Download ZIP`，解压到自己的电脑。按“安装 Skill”把完整目录导入 AI 助手。
2. **准备 Python**：需要 Python 3.10 或更新版本；未安装时前往 [Python 官网](https://www.python.org/downloads/)。代码仅使用标准库，不需要安装额外 Python 依赖。
3. **打开连接向导**：
   - **Mac**：在 Finder 中右键 `配置麦门.command` → “打开方式” → “终端”。向导会弹出分步提示和隐藏输入框。若在 AI 助手里只看到了脚本预览，请先在 Finder 中打开文件，预览窗口不是输入框。
   - **Windows**：双击 `连接麦当劳-Windows.cmd`，按窗口中的步骤操作。需要 Python 安装器提供的 `py` 启动器。
   - **Linux 或其他终端**：在解压目录运行 `python3 local_setup.py --configure`。
4. **获取自己的 Token**：向导会引导前往 [麦当劳官方控制台](https://open.mcd.cn/mcp)，登录 → 控制台 → 按页面提示激活 MCP → 复制个人 Token。Mac 向导可以直接打开控制台；其他系统可点击这里的链接。
5. **回到本机填写**：Mac 在弹出的隐藏输入框中按 ⌘V 粘贴，点击“验证连接”；终端中粘贴后按回车。终端不显示文字或星号是正常现象。
6. **看到“连接成功”后开始摇餐**：回到已安装本 Skill 的 AI 助手，告诉它城市、地标和需求，例如：**“摇个麦门，广州柯木塱附近自取，1人预算30元，500千卡以内。”** 助手会查询真实菜单，而不是让你填写工具参数。

### 没连上怎么办？

| 提示或情况 | 下一步 |
|---|---|
| Token 没有通过验证 / 401 | 到官方控制台重新复制有效 Token，再打开配置入口 |
| 暂时连不上服务 | 检查网络后重试，不必急着换 Token |
| 官方服务限流 / 429 | 稍后再试 |
| 没填写或点击取消 | 不会更改配置，需要时重新打开即可 |
| 已配置后想更新 Token | 再次打开同一个连接向导；新 Token 验证成功才替换旧值 |

验证只查询连接和工具列表，不创建订单。Token 保存在本机 `.private/token`，在 macOS/Linux 上目录权限700、文件权限600，Windows 使用本机目录访问权限，已排除 Git；文件并非加密存储，不要分享整个含 `.private` 的工作目录。原有 Token 在新连接验证失败时保留。

如果暂时不想连接，可请助手生成一句轻松的餐桌寄语；真实菜单、价格、营养与下单需连接后使用。

## 开发者入口

本机向导完成后可使用以下命令；普通用户直接在 AI 助手里说需求即可：

```bash
python3 local_setup.py test
python3 local_setup.py tools
python3 local_setup.py schema query-meals
python3 local_setup.py call query-meals --args-file .private/menu_args.json
python3 local_setup.py nutrition --args-file .private/nutrition_args.json
```

参数文件根据实际 schema 创建。热量参数示例：

```json
{"items":[{"name":"麦辣鸡翅2块","quantity":1},{"name":"圆筒冰淇淋","quantity":1}],"maxKcal":500}
```

直接使用 `python3 -m skill.cli` 时，从本机环境变量 `MCD_MCP_TOKEN` 读取 Token。Skill 的会话行为与确认下单用法见 [SKILL.md](SKILL.md)。

## 对话示例

以下是脱敏后的交互形态，价格和营养数值来自本次官方联调，供应与价格随门店和时间变化，需要实时重查：

> 用户：广州，某地铁站附近自取，1人20元，想吃麦辣鸡翅。
> 助手：这餐要控制热量吗？不控制／尽量清爽／指定单餐上限。
> 用户：500千卡以内。
> 助手：查询门店、真实菜单与份量，核价后推荐麦辣鸡翅2块＋圆筒冰淇淋1个，共20元、约317千卡。若作为正餐不够饱，可调整搭配条件。
> 用户：放开必选鸡翅，不限预算，1000千卡以内，再摇。
> 助手：重新查询、核价后推荐巨无霸＋中薯条＋中杯可乐，共37.5元、约949千卡。
> 用户：锁定巨无霸，换个饮料。
> 助手：保留锁定项，只重新选择饮料，并重新计算价格和热量；用户确认后才创建订单。
